# Horace Goes Skiing — курсовая работа

Аналог игры Horace Goes Skiing (ZX Spectrum) на C++17 + SFML 2.6, тесты на GoogleTest, сборка CMake.

Правила (по оригиналу Melbourne House, 1982): на старте $40. Хорас переходит дорогу к лавке
и берёт лыжи напрокат ($10), затем переходит дорогу обратно и попадает на склон.
Сбила машина — приезжает скорая, увозит Хораса, и за это списывается $10. Жизней нет: кончились деньги — игра окончена.
После заезда Хорас начинает у лавки; если лыжи сломаны — берёт новые.

Дорога: две полосы вправо и две влево; машины иногда перестраиваются,
а чем дольше Хорас переходит дорогу, тем больше машин.

На склоне: проезжай между флажками (пары по очереди красные и синие) — +10 очков,
пропустил ворота — −10 и противный зуммер. Объезжай деревья: три дерева — лыжи сломаны,
заезд окончен. Доехал до финиша — бонус +100. Каждая 1000 очков — +$10.

Готово: дорога целиком, склон со случайной трассой, очки, музыка,
текстуры машин и анимация скорой.

## Что нужно установить

**Везде:** Git и интернет при первой сборке — CMake сам скачает SFML и GoogleTest
(первая сборка занимает несколько минут, дальше быстро).

**Windows**, на выбор:
- **Visual Studio** (Community, бесплатно) — в установщике отметить
  «Разработка классических приложений на C++». CMake там уже есть.
- **CLion** — всё нужное идёт в комплекте.
- **VS Code** — расширения *C/C++* и *CMake Tools* + компилятор (Build Tools for Visual Studio или MinGW) + CMake.

**Linux (Ubuntu/Debian):**
```bash
sudo apt install build-essential cmake git \
  libx11-dev libxrandr-dev libxcursor-dev libxi-dev libudev-dev libgl1-mesa-dev libfreetype-dev \
  libopenal-dev libvorbis-dev libflac-dev
```

**macOS:** `xcode-select --install` и `brew install cmake`.

## Как собрать и запустить

**Visual Studio:** Файл → Открыть → Папка → выбрать папку проекта. Дождаться, пока CMake
всё скачает (внизу окно «Вывод»). Вверху в списке целей запуска выбрать `horace.exe` и нажать ▶.
Тесты: Тест → Обозреватель тестов → Запустить все.

**CLion:** Open → папка проекта. В списке конфигураций выбрать `horace` (игра)
или `horace_tests` (тесты) и нажать ▶.

**VS Code:** открыть папку, CMake Tools предложит выбрать компилятор (kit), затем
внизу кнопки Build и ▶. Тесты — во вкладке Testing.

**Командная строка (любая ОС):**
```bash
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release          # тесты
./build/horace                             # Linux/macOS
build\Release\horace.exe                   # Windows (Visual Studio)
```

Управление: на дороге стрелки — шаг; на склоне ← → — поворот, ↓ — быстрее.
Enter (или пробел) — начать игру в меню / дальше после итогов заезда / в меню после проигрыша.
P — пауза, M — музыка вкл/выкл, N — звуки вкл/выкл, Esc — выход.

**Демо-режим** (для показа игры): нажмите «ё» (клавиша слева от 1) 5 раз подряд —
машины перестают сбивать, деревья не ломают лыжи, слева вверху появляется «ДЕМО-РЕЖИМ».
Ещё 5 раз — выключить. Работает в любой раскладке.

## Звуки

Как на ZX Spectrum: никаких звуковых файлов, только «бипер». Звуки синтезируются в коде
(`src/core/Beeper.cpp`) из квадратной волны — у каждого отсчёта всего два значения, +громкость
или −громкость, как у динамика Спектрума, который умел только «вкл/выкл».
Приёмы: глиссандо (частота плавно едет), вибрато (частота дрожит), «аккорд» (быстрый перебор нот)
и 1-битный шум. Хотите поменять звук — правьте `makeSound()`, громкость — `kLevel` и `kVolume`.

## Таблица рекордов

Лучшие 10 результатов хранятся в файле `highscores.txt` в папке проекта
(по строке на запись: `очки;заезды;имя`). Если результат попал в таблицу,
после конца игры можно ввести имя — буквы (в том числе русские), цифры, до 8 символов.
В меню правила и таблица сменяют друг друга каждые 7 секунд.
Файл в `.gitignore`: у каждого компьютера свои рекорды. Чтобы сбросить таблицу — удалите файл.

## Своя музыка

Положите файл в `assets/music/` с именем `theme.ogg` (можно `theme.mp3`, `.wav`, `.flac`) —
игра подхватит его сама и будет играть по кругу. Нет файла — игра идёт без музыки.
На Windows для звука нужен `openal32.dll`: CMake сам кладёт его рядом с `horace.exe` при сборке.

## Шрифты

- **Press Start 2P** — 8-битный пиксельный шрифт с кириллицей, основной в игре.
  Автор — CodeMan38 (The Press Start 2P Project Authors), лицензия SIL Open Font License 1.1
  (`assets/fonts/PressStart2P-OFL.txt`) — его можно свободно включать в проект и выкладывать.
  Рисуется без сглаживания (`setSmooth(false)`), размеры текста кратны 8.
- **DejaVu Sans Mono** — запасной, если первого нет (свободная лицензия, `DejaVu-LICENSE.txt`).

## Текстуры и спрайты

Всё лежит в `assets/textures/`, пиксель-арт, в игре увеличивается в 2 раза без размытия.

| Файл | Размер | Что |
|---|---|---|
| `car_red/yellow/blue.png`, `van_green.png` | 40×20 | машины (модели 0..3), мордой вправо |
| `ambulance_1.png`, `ambulance_2.png` | 40×20 | скорая, два кадра мигалки |
| `hero_walk_1/2.png` | 24×24 | герой на дороге, два кадра шага |
| `hero_skis_1/2.png` | 24×24 | то же с лыжами на плече |
| `hero_down.png` | 24×24 | герой сбит |
| `skier_straight.png`, `skier_turn.png`, `skier_crash.png` | 15×20 | лыжник: прямо, поворот вправо (влево отражается), упал |
| `tree.png`, `tree_hit.png` | 15×20 | ёлка и задетая ёлка |
| `flag.png` | 8×16 | флажок: полотнище белое, игра перекрашивает в красный/синий/серый |
| `shop.png` | 100×40 | лавка проката (в игре 200×80, две клетки в высоту) |

Герой рисуется чуть крупнее своей клетки (48×48 вместо 40×40), а сбивают его
по-прежнему по клетке 40×40: так он лучше смотрится рядом с машинами.

Их можно перерисовать в Piskel, LibreSprite или Aseprite: главное сохранить имя файла, размер
и прозрачный фон. Если какого-то файла нет, вместо него рисуется прямоугольник.

## Структура

```
src/core/    логика игры — НЕ знает про SFML, поэтому тестируется
  Rect       прямоугольник + проверка столкновения
  Horace     герой: шаги по полю, не выходит за край
  Car        машина: едет, уехав за край — появляется с другой стороны; умеет перестраиваться;
             model — какая текстура
  Ambulance  скорая: приезжает → грузит Хораса → уезжает (этапы AmbulancePhase)
  Beeper     синтезатор звуков в духе ZX Spectrum (1-битная квадратная волна)
  HighScores таблица рекордов: топ-10, чтение/запись файла, имена в UTF-8
  RoadLevel  уровень «Дорога»: лавка, полосы, машины (перестроения, рост трафика), скорая;
             сообщает события (сбили / скорая уехала / дошёл)
  SlopeLevel уровень «Склон»: трасса (ворота, деревья, финиш), камера, урон лыжам
  Game       правила: деньги, очки, состояния Menu → Road → Slope → RunResults → Road …, GameOver;
             итоги заезда RunStats;
             события GameEvent (шаг, удар, ворота…) — по ним app играет звуки
src/app/     всё, что связано с SFML
  main.cpp   игровой цикл: ввод → update(dt) → отрисовка
  Renderer   рисует Game: текстуры машин и скорой, остальное — прямоугольники
  SoundPlayer играет звуки бипера по событиям игры, сирену — пока едет скорая
tests/       модульные тесты GoogleTest на каждый класс из core
assets/      шрифты, музыка, текстуры
```

Главное правило: **логика в `core`, SFML — только в `app`**. Новые классы игры кладите в `core`
и сразу пишите на них тесты.
