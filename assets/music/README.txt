Положите сюда свою песню с именем theme.ogg (или theme.mp3 / theme.wav / theme.flac).
Игра найдёт её сама и будет играть по кругу. Клавиша M — выключить/включить музыку.

Лучше всего .ogg: файл небольшой и SFML с ним работает лучше всего.
Перевести mp3 в ogg можно в Audacity (Файл → Экспорт → Ogg Vorbis)
или онлайн-конвертером.
